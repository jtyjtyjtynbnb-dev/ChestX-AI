ChestX-AI 演示包 · 快速使用说明

适用环境
- Windows 10/11 64 位（Linux/macOS 使用 start.sh）
- Python 3.10 或更高版本，64 位
- 首次安装 Python 依赖需要联网；Qwen 问答也需要联网

启动步骤
1. 将整个 ZIP 解压到一个有写入权限的文件夹。
2. 双击 start.bat。
3. 脚本会自动检测 Python 与依赖；缺失时在包内创建 .venv 并安装 requirements.txt，可能需要几分钟。
4. 启动成功后自动打开 http://127.0.0.1:8000/。使用期间保持启动窗口开启。

端口
- 前端与后端共用 8000 端口，不再使用 8765。
- 如 8000 被占用：在命令行执行 set CHESTX_API_PORT=8001 后再运行 start.bat。

Qwen 配置
- 方式一：页面右上角“设置” → Qwen AI 服务 → 填写 DashScope API Key → 测试连接 → 保存。
- 方式二：编辑 backend/.env：
  DASHSCOPE_API_KEY=sk-你的Key
  QWEN_MODEL=qwen3.8-flash
- 保存后会写入 backend/.env，下次启动自动读取；该文件不会打进演示 ZIP。
- 未配置时系统仍可运行，问答与报告自动使用本地知识库兜底。

数据与隐私
- 家庭成员与档案保存在 backend/data/chestx.db；浏览器 localStorage 另存一份。
- 演示人物为虚构数据；请勿录入真实患者身份信息或敏感影像。
- 本系统仅供健康科普与教学演示，不作为临床诊断依据。

更多功能、排障、打包与验收步骤见《操作手册.md》。
