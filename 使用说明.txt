ChestX-AI 演示包

适用环境
- Windows 10/11，64 位
- Python 3.10 或更高版本
- 首次启动需要联网安装 Python 依赖；Qwen 问答也需要联网

启动步骤
1. 将整个 ZIP 解压到一个有写入权限的文件夹。
2. 双击文件夹中的 start.bat。
3. 首次启动会在本文件夹创建 .venv 并安装依赖，可能需要几分钟。
4. 启动成功后会自动打开浏览器。使用期间保持启动窗口开启。

Qwen 配置
- 打开网页右上角的设置，在 AI 配置中填写当前电脑可用的 DashScope API Key。
- 使用连接测试确认配置成功；配置文件位于 backend/.env。
- 默认模型为 qwen3.8-flash，可在 AI 设置中切换支持的模型。
- 启动时会读取 backend/.env；设置页临时修改的 Key 只在当前运行期间生效。
- 此演示包按要求包含 API 凭据，请勿公开转发或上传到公共网盘、代码仓库。

端口说明
- 默认后端端口为 8000，前端端口为 8765。
- 如果前端端口被其他程序占用，启动器会尝试后续可用端口并打开对应页面。
- 如后端端口已被其他程序占用，请先关闭占用程序，或设置 CHESTX_API_PORT 后再运行 start.bat。

模型文件和演示胸片已包含在包内。诊断和问答仅供健康科普参考，不能替代医生诊断。
